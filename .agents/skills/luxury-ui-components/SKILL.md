# Luxury Spa UI Components Blueprints

This skill provides step-by-step procedures and ready-to-use component patterns matching the high-end healing/wellness aesthetic of Xile Spa.

## Recommended Components Workflow

1. **Section Structure Hierarchy:**
   - [Hero.astro]: Atmospheric banner with soft gradient overlay, serif H1, primary/secondary CTA, trust badges.
   - [USPs.astro]: 3-4 feature cards with delicate icons, highlighting organic herbs, master therapists, and tranquil ambiance.
   - [FeaturedServices.astro]: 3-4 hero service cards with duration, price tag, and "Tư Vấn Ngay" CTA.
   - [SocialProof.astro]: Verified client testimonials with 5-star badges and glowing reviews.
   - [LocationContact.astro]: Working hours, address, Google Maps embed, and direct call/chat buttons.
   - [FloatingContact.astro]: Sticky bottom-right floating bar with Zalo and Messenger (animated pulse).

2. **Aesthetic Checkpoints for Every Component:**
   - Nền kem `#FDFBF7` hoặc trắng ngà `#FAF9F6`.
   - Font heading Serif (`Cormorant Garamond` hoặc `Playfair Display`).
   - Bo góc lớn (`rounded-2xl` hoặc `rounded-3xl`).
   - Đổ bóng nhẹ ấm (`shadow-spa-soft`).
   - Nút bấm chính màu đồng ánh kim (`bg-spa-bronze`).
